
# 🚀 Silk Road - E-commerce Platform

**Silk Road** is a powerful and modern e-commerce platform developed as a final year BCA project at **Brainware University**. It aims to provide a seamless shopping experience for users and an efficient management system for businesses.

## 🧰 Tech Stack
- **Frontend:** `HTML`, `CSS`, `JavaScript`, `Bootstrap`
- **Backend:** `Django`
- **Database:** `MySQL`
- **Payment Integration:** `Razorpay`

---

## ✨ Features

### 🛍️ User Features
- 🔍 Product browsing, filtering & search functionality
- 🛒 Interactive shopping cart with live updates
- ✅ Secure user registration, login & password recovery
- 💳 Secure checkout with Razorpay integration
- 📦 Real-time order tracking and history
- 🌟 Smart product recommendations
- ⭐ Product reviews and star ratings

### 🧑‍💼 Admin Features
- 📊 Dashboard with metrics and reports
- 📦 Inventory management (CRUD operations)
- 🧾 Order management & status updates
- 📈 Sales analytics and customer insights
- 🛠️ Manage user accounts and feedback

---

## 🧱 System Design
- RESTful APIs for frontend-backend interaction
- Scalable MySQL database structure
- Secure sessions and encrypted credentials
- Responsive design for all device sizes
