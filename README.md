# 🚀 Silk Road – E-Commerce Platform

**Silk Road** is a sleek and powerful e-commerce platform built as a final-year BCA project at **Brainware University**. It provides a smooth shopping experience for users and a robust admin interface for businesses.

## 🧰 Tech Stack

- 🎨 **Frontend:** HTML, CSS, JavaScript, Bootstrap  
- ⚙️ **Backend:** Django  
- 💽 **Database:** MySQL  
- 💳 **Payment Gateway:** Razorpay  

---

## ✨ Features

### 🛍️ User Features
- 🔍 Browse, filter, and search products
- 🛒 Dynamic cart with real-time updates
- 🔐 Secure sign-up/login & password recovery
- 💳 Seamless checkout with Razorpay
- 📦 Track orders in real-time
- 🤖 Smart product suggestions
- ⭐ Leave product reviews & ratings

### 🧑‍💼 Admin Features
- 📊 Dashboard with key metrics
- 📦 Manage inventory with full CRUD
- 📋 Handle orders & update statuses
- 📈 Get insights from sales analytics
- 👥 Manage user feedback & accounts

---

## 🧱 System Design Highlights

- RESTful APIs for smooth frontend-backend flow  
- Encrypted credentials & secure session handling  
- Scalable MySQL DB schema  
- Responsive design for mobile & desktop
